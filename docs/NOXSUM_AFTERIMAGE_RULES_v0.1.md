# NOX残像表示ルール v0.1

Placement Boardに確定配置されたNOXは、異なる瞬間に残された「過去の痕跡」として表示する。Inventoryは配置しようとしている姿、Shadow Plateはその結果として残った影。盤面上には一匹のNOXの複数の瞬間が重なる。

正本：[NOXSUM_GRANT36_MASTER_SPEC_v1.0](NOXSUM_GRANT36_MASTER_SPEC_v1.0.md)。提出版の `grant-submission-2026` は動かさず、その後の変更として扱う。

## 表示

| 状態 | 猫画像のalpha |
| --- | ---: |
| Inventory | 100% |
| ドラッグ中・再ドラッグ中のNOX | 100% |
| Placement Boardの確定配置（固定NOXを含む） | 45% |
| hover・キーボードfocus・押下中の選択 | 70% |
| SLEEP rail | 現行の100% |
| Solve演出中 | 45%（最後の配置だけ通常の配置フェードを完了する） |

提案内のhover 60%／70%の相違は、基本表と末尾の実装要約に合わせ、v0.1では70%を採用する。ドラッグ先の枠ハイライトは選択とは扱わない。ドラッグ元は過去位置の45%の痕跡を保ち、ポインターに追従するNOXを100%で表示する。

既存の画像・切り抜き・毛柄・姿勢・WALK方向を保持し、猫画像のalphaだけを変える。枠、座標、固定マーカー、SLEEPの遮光状態は薄くしない。色相・彩度の変更、アウトライン、粒子、専用画像、shader、足跡、時系列番号、影への線は追加しない。

## 配置と復元

- タップ配置・有効なドラッグ移動：100%で0.25秒保持し、0.40秒かけて45%へ。hover／選択中なら70%を下限とする。
- 影は既存の更新タイミングで反応し、変化した影セルの1.2秒の縁取りと残像フェードを重ねる。影計算やSolve判定は待たせない。
- Reduced Motion：保持・フェードなしで残像表示へ即時切替。hover／選択の70%と既存の影フィードバック仕様は維持。
- Remove：画像を即時に除去。新しい消失演出は設けない。
- Undo・ステージ読込・リセット・解答表示：一時的な配置フェードを破棄し、現在の配置と操作状態からalphaを再計算する。復元時に100%の配置演出を再生しない。
- alphaは履歴・セーブに保存しない。既存の `posts` に含まれる有効な盤面socketを確定配置として読む。保存形式、光学計算、ステージデータは変更しない。

## 実装と検証

`src/ui/experiment_surface.gd` が描画alphaと一時的な配置時間を担当し、`src/experiment_main.gd` が配置・操作・復元のタイミングを渡す。SLEEPとInventoryは残像描画の対象外。

統合スモークは以下で実行できる。

```powershell
& "$env:USERPROFILE/tools/godot-4.7/Godot_v4.7-stable_win64_console.exe" --headless --debug --ignore-error-breaks --path . --script res://tools/nox_afterimage_smoke.gd
```

配置の保持・フェード、実ポインターhover、focus、タッチ選択、再ドラッグ、無効drop、Inventory返却、Undo、Remove、WALK回転、ステージ切替、Reduced Motion、Solve、保存内容、旧キャンペーンを確認する。

`NOXSUM_CAPTURE_DIR` に出力先の絶対パスを指定し、`--headless` を外すと、360×800／720×900のGR03・GR08・GR16・GR19を撮影する。姿勢とWALK両方向の可読性を確認し、45%で判読困難なら50〜55%への調整を優先する。
