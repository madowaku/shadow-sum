# Audio sources

The game rotates through four OpenTracks/DOVA-SYNDROME BGM tracks in this order. Each track plays once, then the playlist advances; after the fourth track it returns to the first.

1. “The Most Human Computer” by Makoto Hiramatsu — https://opentracks.com/bgm/detail/4768
2. “論理的思考” by Phalene — https://opentracks.com/bgm/detail/9090
3. “オルゴールワールド” by マニーラ, track 1 (non-loop arrangement) — https://opentracks.com/bgm/detail/23304
4. “ガラス張りの三角錐” — https://opentracks.com/bgm/detail/8127

The MP3 files are bundled as background music for the game and imported by Godot. OpenTracks' license and each creator's conditions apply. Phalene's profile prohibits use in R-18 content. The source pages are retained above; the OpenTracks license is at https://opentracks.com/help/articles/license/.

UI and gameplay SFX are documented separately with their asset licenses when present.
